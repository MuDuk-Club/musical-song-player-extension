## 🎭 뮤지컬 넘버 컬렉션
뮤지컬 넘버 모아듣기 Chrome 확장 프로그램
```
- YouTube 뮤지컬 넘버 링크 모음
- 개인 사용 목적으로만 제작된 Chrome 확장 프로그램입니다
- YouTube 콘텐츠의 저작권은 각 저작권자에게 있습니다
- 상업적 사용이나 배포를 금지합니다
```
### 🚀 설치 방법

1. **확장 프로그램 코드 다운로드**
<img width="450" height="370" alt="image" src="https://github.com/user-attachments/assets/5fd9560c-f487-45ea-a58f-b092ef5add5e" />

2. **개발자 모드로 설치**
   - Chrome에서 `chrome://extensions/` 접속
   - 우측 상단의 "개발자 모드" 활성화
   - "압축해제된 확장 프로그램을 로드합니다" 클릭
   - 프로젝트 폴더 선택

3. `musical-songs.json` 파일에 원하는 플리 추가 가능

### 📖 사용법

#### 기본 사용
1. **확장 프로그램 아이콘 클릭**: 브라우저 툴바에서 아이콘을 클릭하여 팝업 열기
2. **검색**: 상단 검색창에 원하는 뮤지컬이나 노래 제목 입력
3. **필터링**: 태그 버튼을 클릭하여 카테고리별 필터링
4. **재생**: 원하는 넘버를 클릭하면 새 창에서 자동 재생

#### 즐겨찾기 관리
- **즐겨찾기 추가**: 하트 아이콘을 클릭하여 즐겨찾기에 추가
- **즐겨찾기 보기**: "즐겨찾기" 탭에서 저장된 넘버들 확인
- **즐겨찾기 제거**: 즐겨찾기된 넘버의 하트 아이콘을 다시 클릭하여 제거
